# Semantic BI Fuseki Dashboard

Небольшой read-only веб-дашборд статистики именованных графов. Интерфейс не требует авторизации. Сервер по умолчанию слушает только `127.0.0.1` и хранит Fuseki credentials на серверной стороне.

## Что показывает

- общее число графов в заданном пространстве URI;
- количество графов по типам `deal`, `activity`, `user`, `category`, `stage`, `source`;
- распределение графов по датам из RDF-предиката `b24:createdAt`;
- автоматическое обновление раз в 20 секунд, чтобы отображать ход загрузки.

SPARQL-запросы находятся в `queries/graphs_in_scope.rq` и
`queries/graphs_by_created_at.rq`. Сервер подставляет в шаблоны `GRAPH_PREFIX`
как SPARQL-литерал перед отправкой в Fuseki.

Дата относится к созданию исходной сущности в Bitrix24, а не к моменту импорта в Fuseki. Для сущностей без `createdAt` граф учитывается в общем количестве и по типу, но не попадает в график дат.

## Запуск

Нужен Python 3.10 или новее; внешние Python-пакеты не используются.

```bash
cp .env.example .env
# Заполнить FUSEKI_USERNAME и FUSEKI_PASSWORD, если Fuseki требует Basic Auth.
python3 server.py
```

Откройте <http://127.0.0.1:8080>. `.env` читается только сервером и исключён из Git. Не вставляйте Fuseki credentials в HTML или браузерный JavaScript.

Можно задать адрес набора и пространство графов через `.env`. `GRAPH_PREFIX` — начало URI графов, например `urn:bitrix24:entity:garpix-bitrix24-ru:`. Для использования другого набора задайте соответствующий `FUSEKI_URL`.

## Режим доступа

Приложение выполняет только SPARQL `SELECT` к endpoint `/query`. В приложении нет маршрутов обновления Fuseki. Без авторизации веб-интерфейс по умолчанию доступен лишь на локальной машине. Чтобы открыть его в сети, задайте `DASHBOARD_HOST=0.0.0.0` и ограничьте доступ сетевыми средствами.

Описание OWL 2 аксиомы классификации активности см. в [ONTOLOGY.md](ONTOLOGY.md).
